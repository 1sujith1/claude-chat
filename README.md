# Claude Chat

A single-page chat client for the Anthropic Messages API. Open the site, paste your API key in Settings, and chat.

- Text, image (PNG/JPEG/GIF/WebP), PDF and text-file attachments (button, drag and drop, or paste)
- Model picker (or load your account's models), effort, thinking mode and display, max tokens
- System prompt, stop sequences, temperature / top_p / top_k, web search, PDF citations, streaming, service tier
- Extra request JSON and anthropic-beta header for anything else the API supports
- Chats and settings are stored in your browser's localStorage. The key is only sent to the API base URL.
